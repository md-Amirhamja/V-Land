# Rulebook digest (LandTech 2026) - one page

Full text: `docs/source/LandTech-2026-RuleBook.txt`. Plan: `docs/PLAN.md`. Problem statement chosen: **P5 - Citizen Pre-Purchase Verification**.

| Section | Rule in short |
| --- | --- |
| 3 (P5) | A "check before you buy" tool: verify ownership, mutation history, pending cases, khas/acquisition status before a transaction. |
| 6.1 | Round 1 (online): submit project + concept note on the LandTech platform by **16 Oct 2026**. Up to 25 teams reach the Final. |
| 6.2 | Final: improve Round 1 project, present the latest version live; both students attend in person. |
| 7.2 | Open-source libraries/APIs/public datasets allowed if licences are respected and sources credited in the README. |
| 7.3-7.4 | No uncredited copying. Keep the repository **with its commit history** (no history rewriting). |
| 7.5 | Changes between Round 1 and the Final are summarised in the README. |
| 8.1-8.2 | **Synthetic data only.** No real names, NID numbers, phone numbers, addresses or real land records. |
| 8.3 | No scraping / automated querying / bulk download of any government portal. |
| 8.4 | No security or penetration testing of live government or third-party systems; demonstrate security only on our own prototype. |
| 8.5 | Any real document used in a demo must be fully anonymised and approved in advance. |
| 9 | AI tools allowed; **disclose every tool in the README**. Both students must be able to explain the code and design. |
| 10.1 | Round 1 submission: concept note (PDF, max 4 pages), repo link + README (setup, data sources, AI disclosure), demo video (max 3 min), live link (recommended). |
| 10.2 | Final submission: updated repo (README lists changes since Round 1) + pitch deck PDF (max 10 slides). Late = not accepted. |
| 11 | Final: 5 min pitch + live demo, 3 min Q&A, Bangla or English. **Both students present; mentors may not speak for the team.** |
| 14 | Disqualification: false info, plagiarism, breaking section 8, missing a deadline, unapproved team change, unpaid fee. |

The judging rubric is a separate document that has not been provided yet.
